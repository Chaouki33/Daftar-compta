# Daftar Compta

Application web de comptabilité générale selon le **Plan Comptable Marocain (PCM)**.

## Structure

```
index.html      Page principale
css/style.css   Styles (thèmes clair / sombre)
js/compta.js    Logique comptable : plan de comptes, balances, CPC, bilan
js/app.js       Interface utilisateur
```

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucune installation requise.
Les données sont enregistrées localement dans le navigateur (`localStorage`).
